Bizfolio
Bizfolio is a cloud-based application designed to streamline the process of managing, sending, and signing documents.
Built using ReactJS for the frontend and .NET for the backend, this platform enables users to create customizable,
signable documents by adding draggable fields, allowing recipients to easily fill in required information. Bizfolio
provides an intuitive and secure way to handle electronic document workflows, making it especially useful for
businesses and legal professionals.
Cloud-Based Platform: BizFolio operates entirely in the cloud, ensuring easy access and secure document handling
from anywhere.
Drag-and-Drop Fields: Users can drag and drop various input fields (e.g., text boxes, date pickers, checkboxes) onto
documents, customizing them for each recipient.
Electronic Signatures: Recipients can sign documents electronically, eliminating the need for paper-based processes.
Text Editor Module: Developed the core Text Editor Module, enabling users to easily edit, format, and style text within
documents, ensuring all content appears professional and tailored to the recipient.
Backend Integration with .NET: Implemented robust backend services with .NET to handle user authentication,
document storage, and secure data management.
Real-Time Updates: Integrated real-time document editing and signing functionality, ensuring a smooth and
responsive user experience.
